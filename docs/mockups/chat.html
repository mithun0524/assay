B · Artifact block recommended

Narration streams in, then one grouped block with a status line and a collapsed action list. Click a row to open the file.

Pattern read from bolt.diy’s Artifact.tsx source.
  • Four states per row: queued ○ · running ◌ · done ✓ · failed ✗
  • Collapsed by default — the summary line is enough.
  • Code never enters the chat. Shell commands do; they’re one line.

C · Minimal narration lovable-ish

Text plus a single shimmering status line. No list at all — you watch the preview, not the chat.

  • Calmest of the four. Nothing to read while it works.
  • Nothing to click when it goes wrong, and no sense of scale.
  • Good fit for Simple mode if paired with the Build surface.

D · Compact log developer

Maximum density for a long build. A Developer-mode option, wrong as the default.

  • A 40-turn build stays on one screen.
  • Mono everything is hostile to a non-technical user.
